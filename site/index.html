Did the AI keep every fact?

Language models often sound fluent while quietly dropping a negative, misconverting a number scale, or elevating uncertain wording into a settled fact. Asking another model to double-check adds latency and still lets silent edits slip through.

Between the Lines (btl) is a local Python verification CLI and MCP server with zero external LLM calls. Below are six real runs exported straight from the engine, showing how it audits translations, compares document revisions, collapses syndicated wire copies, and ranks candidate evidence.
